# Módulos Principales de un IDE (Visual Studio Code)

### 1. Editor de Código
Es el espacio central donde se escribe el software. Cuenta con **resaltado de sintaxis**, que permite relacionar visualmente secciones el codigo, asigna colores diferenciados a palabras clave, variables y cadenas de texto para facilitar la lectura visual de la estructura del código. Además, incluye **autocompletado** (IntelliSense), una herramienta que predice y sugiere fragmentos de código en tiempo real, lo que agiliza la escritura y reduce los errores tipográficos.

### 2. Explorador de Archivos
Es el panel lateral que muestra de forma gráfica la estructura de directorios del proyecto. Su utilidad principal es permitir al desarrollador buscar, crear, eliminar y organizar carpetas o archivos específicos de manera rápida. Aunque en proyectos pequeños su uso parece simple, se vuelve indispensable en desarrollos grandes para mantener el orden y la navegación entre múltiples componentes.

### 3. Terminal Integrada
Es una línea de comandos integrada directamente en la interfaz del entorno. Permite ejecutar el código de y probar el programa sin necesidad de cambiar de ventana ni lidiar con ventanas emergentes externas. Esto centraliza el flujo de trabajo en un solo lugar, ofreciendo comodidad, orden y la posibilidad de ejecutar comandos del sistema operativo simultáneamente.

### 4. Depurador (Debugger)
Es la herramienta diseñada para identificar y corregir errores en el código de forma eficiente. A través de *breakpoints* (puntos de interrupción), permite pausar la ejecución del programa en una línea específica para inspeccionar el valor de las variables en tiempo real. En lugar de buscar fallas a ojo línea por línea, el depurador ahorra tiempo al permitir seccionar el código y aislar el origen exacto del problema.

### 5. Control de Versiones (Git)
Es el sistema que registra el historial de cambios del código fuente. Su utilidad principal es mantener el orden y ahorrar espacio en el disco, evitando la creación de múltiples archivos repetidos. Además de facilitar el trabajo colaborativo sin confusiones, permite al desarrollador revertir el código a estados anteriores de forma segura para recuperar funciones descartadas o corregir errores recientes.

### 6. Extensiones / Plugins
Son complementos desarrollados por la comunidad que se instalan para añadir capacidades al entorno de desarrollo. Permiten personalizar la herramienta según las necesidades exactas del programador, abarcando desde mejoras estéticas hasta la incorporación de herramientas críticas que no vienen por defecto como el soporte para el lenguaje Python. Gracias a esto, un editor ligero se transforma en un IDE completo.
